# Аналіз жанрового розподілу фільмів у датасеті *movies_metadata.csv*

## 📌 Опис проєкту

Цей проєкт виконує базову аналітику жанрів фільмів на основі датасету *movies_metadata.csv*.  
Основна мета — підготувати дані, очистити їх, перетворити колонку жанрів у структурований формат та визначити, які жанри є найпоширенішими.  
У фіналі будується візуалізація, що дозволяє швидко оцінити жанровий баланс каталогу.


## 📂 Використані дані

Аналіз здійснюється на основі CSV-файлу, що містить метадані фільмів.  
У роботі використовуються такі ключові колонки:

- **tagline** — слоган фільму; пропуски замінюються технічним значенням.
- **homepage** — офіційна сторінка фільму; пропуски заповнюються заглушкою.
- **belongs_to_collection** — інформація про колекцію; відсутні значення замінюються порожнім об’єктом.
- **genres** — жанри фільму у текстовому форматі, подібному до JSON (список об’єктів із `name`).

Після базового заповнення пропусків усі записи, де залишились NaN, видаляються.


## 🔧 Основні кроки обробки даних

1. **Завантаження** датасету у форматі DataFrame.  
2. **Очищення пропусків** у ключових полях (`tagline`, `homepage`, `belongs_to_collection`).  
3. **Видалення неповних записів**, що містять інші пропуски.  
4. **Перетворення жанрів**:
   - текстові записи з жанрами конвертуються у Python-список,
   - із кожного елемента витягується лише назва жанру,
   - жанри зберігаються у вигляді списку текстових значень.
5. **Формування частотного розподілу жанрів** методом підрахунку кількості їх появ.  
6. **Побудова візуалізації** у вигляді стовпчикової діаграми.


## 📊 Отримані результати

У результаті виконання аналізу формується:

- **Очищений датасет**, готовий до подальшої аналітики.
- **Структурована колонка жанрів**, що містить список текстових назв для кожного фільму.
- **Частотний розподіл жанрів** — кількість фільмів у кожному жанровому напрямі.

Результати дозволяють:

- виявити найпоширеніші жанри в базі,
- оцінити жанрову різноманітність,
- сформувати уявлення про структуру контенту.


## 📈 Візуалізація

![Візуалізація жанрів](Figure_1.png)

Побудовано стовпчиковий графік:

- **Вісь X** — назви жанрів.  
- **Вісь Y** — кількість фільмів у кожному жанрі.  
- Підписи жанрів повернуті для кращої читабельності.  
- Графік дозволяє швидко зрозуміти, які жанри домінують у каталозі.

Ця візуалізація є основним аналітичним результатом і використовується для первинного ознайомлення із жанровою структурою.
